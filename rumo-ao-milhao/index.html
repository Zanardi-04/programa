    Backup e restauração

    As informações são guardadas neste iPhone, não no GitHub. Exporte uma cópia regularmente para o app Arquivos ou iCloud Drive, porque limpar dados de sites ou remover o app pode apagar os registros locais.

    Restaurar substitui os registros atuais após sua confirmação.

    Funciona sem internet

    Após a primeira abertura e instalação pelo Safari, o app pode funcionar offline. O GitHub Pages hospeda apenas os arquivos do programa; seus valores não são enviados a ele.

    Verificando disponibilidade offline...

    Recomenda-se abrir o app uma vez com internet antes de usar offline.
